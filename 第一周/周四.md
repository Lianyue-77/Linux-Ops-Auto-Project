# 文件内容查看命令

## 1. cat 一次性查看整个文件

```
cat /etc/profile
cat /etc/passwd
```

## 2. more 分页查看（回车往下翻）

```
more /etc/profile
```

## 3. less 分页查看（上下键滚动，q 退出）

```
less /etc/profile
```

## 4. head 只看前 10 行

```
head /etc/profile
# 自定义看前5行
head -n 5 /etc/profile
```

## 5. tail 只看末尾 10 行

```
tail /etc/profile
# 看最后3行
tail -n 3 /etc/profile
```

## 6. tail -f 实时监控日志（工作超常用）

```
tail -f /var/log/messages
```

按 `Ctrl + C` 退出监控



# 今日实操作业

1. 依次用 `cat、more、less` 看 `/etc/profile`
2. 用 `head` 看前 5 行、`tail` 看最后 3 行
3. 练习 `tail -f` 实时看系统日志，然后退出
4. 把每条命令多敲两遍练熟
