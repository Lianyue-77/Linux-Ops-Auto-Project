# 打包压缩解压 tar、zip、unzip

## 一、tar 打包压缩（Linux 最常用）

### 1. 仅打包，不压缩

```
tar -cvf ops.tar ops/	#将ops目录下的内容打包并显示过程
```

### 2. 打包并 gz 压缩

```
tar -zcvf ops.tar.gz ops/
```

### 3. 查看压缩包内文件

```
tar -ztvf ops.tar.gz
```

### 4. 解压到当前目录

```
tar -zxvf ops.tar.gz
```

### 5. 解压到指定目录

```
tar -zxvf ops.tar.gz -C /tmp/
```

## 二、zip /unzip 压缩解压

在安装之前要注意，由于Centos官方源早已停服，正常是无法从官方源下载的；这里我们就需要更换源来进行操作

```
# 备份原有源文件
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.bak
# 下载阿里centos7源
curl -o /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
# 清空并重建yum缓存
yum clean all && yum makecache
```



```
yum install -y zip unzip
```

### 1. 压缩文件夹

```
zip -r ops.zip ops/
```

### 2. 解压 zip 包

```
unzip ops.zip
```

### 3. 解压到指定目录

```
unzip ops.zip -d /tmp/
```

## 今日实操作业

1. 把你之前建的 

   ```
   ops
   ```

    目录，分别打成：

   - ops.tar
   - ops.tar.gz
   - ops.zip

   

2. 练习查看压缩包内容

3. 练习解压到当前目录、解压到 /tmp 目录

4. 多敲两遍，记住参数含义：

   - c 创建  v 显示过程  f 指定文件  z gz 压缩  x 解压 t查看



### 拓展

```
#打包和压缩
gzip
#压缩单个文件
gzip protocols
#压缩多个文件，每一个文件产生一个单独的压缩包
gzip  hosts passwd shadow
#解压缩
gzip -d hosts.gz passwd.gz protocols.gz shadow.gz 
```

#解压rar包
