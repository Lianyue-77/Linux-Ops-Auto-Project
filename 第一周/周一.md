退出**nmtui**工具重启网卡

```
systemctl restart NetworkManager	#使用nmtui工具是与NetworkManager有关

#拓展指令
vi /etc/sysconfig/network-scripts/ifcfg-ensxx	#编辑网卡文件
systemctl restart network	#该指令是针对修改网卡配置文件的重启
#重启网卡设备
nmcli device connect ensxx
```

查看ip信息

```
ip addr	#展示ip信息

#若是出现多余的ip，则可使用该指令删除
ip addr del 192.168.xxx.xx/24 dev ensxx
```
