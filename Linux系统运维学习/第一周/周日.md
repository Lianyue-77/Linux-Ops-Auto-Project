## 三、综合实操小任务（必做，自测有没有学会）

你独立完成，不看之前教程：

1. 在家目录创建层级目录：

```
project/ops/shell
```

1. 在 shell 里面 创建 3 个文件：

```
a.txt  b.log  c.sh
```

1. 复制 a.txt 备份为 a_bak.txt
2. 把 b.log 移动到 project/ops 目录
3. 查看 c.sh 前 5 行内容
4. 全盘查找后缀 `.sh` 的文件
5. 在 /etc/profile 中过滤关键字 `PATH`
6. 把整个 project 目录 打包压缩为：`project.tar.gz`
7. 把压缩包解压到 /tmp 目录
