# 文件操作全套命令

## 1. 创建空文件

```
touch file1.txt
touch file2.log file3.sh	#创建多个文件用空格隔开
#另一个目录下创建多个文件
touch test/{file1.txt,file2.txt,file3.txt}	#使用花括号包裹，逗号隔开；
```

## 2. 复制文件

```
# 拷贝file1.txt 成 file1_bak.txt
cp test/file1.txt file1_bak.txt

# 把文件拷贝到 a 目录里
cp file2.log a/
```

## 3. 移动 / 重命名

```
# 移动文件到指定目录
mv file3.sh a/b/

# 同目录移动=重命名
mv file1_bak.txt file1_new.txt
```

## 4. 删除文件（谨慎用！）

```
rm file1_new.txt
# 交互式删除，要输入 y 确认
```

## 5. 强制删除，不提示

```
rm -f file2.log
```

## 6. 删除文件夹 + 里面所有内容

```
rm -rf a/
```

记住：**rm -rf 工作中千万别乱敲，只在自己虚拟机练习**
