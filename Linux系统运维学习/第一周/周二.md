# 周二

# 目录操作全套命令

## 1. 查看当前所在目录

```
pwd
```

## 2. 查看当前目录下文件 / 文件夹

```
ls
ls -l
ls -lh	
#-l 和 -lh前者是以B（字节）为单位来显示大小；
#而后者则是使用人性化单位会根据文件大小自动以合适的单位显示
```

## 3. 创建单个文件夹

```
mkdir test1
```

## 4. 一次性创建多层级目录（重点必会）

```
mkdir -p a/b/c
#创建同级目录则是使用空格隔开

mkdir -p dd/{c,d,e}		#想在dd目录下创建多个同级目录则可以使用花括号包裹，以逗号隔开
```

## 5. 进入文件夹切换目录

```
cd test1
cd ..
cd a/b/c
cd ~
```

`cd ..` 返回上一级

`cd ~` 直接回到家目录

## 6. 删除空文件夹

```
rmdir test1

rm -rf xx	#可用于直接删除，删除目录及目录下的目录文件只需要删除该目录即可
```

## 7. 实操作业（必须自己做一遍）

1. 在根目录下创建目录：`ops`
2. 在 ops 里面再建：`shell`、`ansible` 两个文件夹
3. 来回 cd 切换进去、退出来
4. 用 ls -l 看结构
