# 文件权限 chmod、chown、chgrp

## 1. 查看文件权限

```
ls -l test.txt
```

## 2. 数字权限修改（最常用）

```
chmod 755 test.txt	
chmod 644 test.txt
chmod 777 test.txt
```

> 4 读 r 2 写 w 1 执行 x

## 3. 符号权限修改

```
chmod u+x test.txt
chmod g-w test.txt
chmod o+r test.txt
```

## 4. 修改文件属主

```
chown user01 test.txt
```

## 5. 修改文件所属组

```
chgrp dev test.txt
```

## 6. 同时改属主 + 属组

```
chown user01:dev test.txt
```
