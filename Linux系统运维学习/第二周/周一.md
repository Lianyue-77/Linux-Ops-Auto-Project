# 用户与用户组管理实操命令

## 1. 查看系统已有用户

```
cat /etc/passwd
id root
```

## 2. 创建用户

```
useradd test01
# 设置密码，回车后输入密码
passwd test01		
#正常设置密码是≥8 位，大小写 + 数字 + 符号组合

#拓展
# --stdin 标准输入一键改密，root无视密码策略
echo "123456" | passwd --stdin test01
```

## 3. 创建指定附属组的用户

```
groupadd ops
useradd -G ops test02
id test02
```

## 4. 修改用户附属组

```
usermod -aG ops test01
id test01
```

## 5. 删除用户（-r 连带家目录一起删）

```
userdel -r test02
```
